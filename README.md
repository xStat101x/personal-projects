## AI Pentester account separation

This collection is an independent copy maintained on xStat101x. The private working fork and upstream remain unchanged. No AI account has collaborator access to this collection. Published content is readable by anyone; GitHub account separation controls write access, not access to public code.

## Getting started

See each project folder for its files and notes. For the AI reference corpus, clone this repository with submodules using `git clone --recurse-submodules <repository-url>`. The original corpus commit pointers are preserved. Scripts and tools were not executed as part of migration.
